Student Study Resources Sharing Website



A simple and user-friendly webpage that helps students discover and access useful study resources for their academic preparation.



🌟 Project Overview



The Student Study Resources Sharing Website is a web-based webpage designed to provide useful educational resources in an organized and attractive way.



Students can easily access:



📚 Study Materials

💻 Programming Tutorials

📐 Mathematics Resources

🧑‍💻 Computer Science Resources

🔗 Useful Educational Websites



The project also demonstrates the use of Git and GitHub for version control, commits, branching, merging, and deployment using GitHub Pages.



✨ Features

📚 Study Resources



Provides a collection of useful educational resources for students.



🔗 Resource Links



Students can directly access external websites and learning platforms through clickable links.



🎨 Simple \& Responsive Design



The webpage is developed using HTML and CSS and is designed to work on different screen sizes.



🌐 GitHub Pages Deployment



The website can be hosted online using GitHub Pages and accessed through a public URL.



🔄 Git Version Control



Git is used to track changes through multiple commits and maintain the development history of the project.
